# NearbyJobsMap 데이터 계약 기반

잡코리아와 알바몬의 소규모 공개 표본을 이용해 공고 정보를 손실 없이 읽고 비교 가능한 형태로 정규화하는 TypeScript parser workspace다. 장래 제품은 로컬 우선 통합 채용 목록이 주 인터페이스이고, 지도는 현재 필터 결과의 근무지 분포를 보조적으로 탐색하는 기능이다.

## 현재 범위

- 활성 소스: 잡코리아, 알바몬
- 결과물: 소스별 fixture parser, `CanonicalJob`, 급여 파싱·선택적 월 환산, 위치 정확도, 공고 상태, 중복 판별, 계약 진단
- 고용24: 향후 공식 API 검토 대상인 roadmap 소스다. 현재 adapter·fixture·정규화 코드는 없다.
- 포함하지 않음: 네트워크 수집, production crawler, UI, 지도, 데이터베이스, 스케줄러, 배포

이 저장소는 잡코리아나 알바몬의 공식 파트너 연동이 아니다. production crawler는 아직 포함하지 않는다. 기술적으로 공개 페이지가 열리는 사실은 수집·재사용 허가를 뜻하지 않는다.

## 구조와 원칙

`src/domain`은 공통 모델, `src/sources`는 서로 격리된 parser와 정규화 경계, `src/services`는 공통 순수 함수를 담는다. parser에는 네트워크 접근이 없다. 알바몬의 관찰된 내부 BFF는 공식 API가 아니며 현재 코드가 호출하거나 의존하지 않는다.

급여·주소·근무일의 원문은 보존한다. 환산 월급은 비교용 추정 메타데이터이며 원문을 대체하지 않는다. 관찰 좌표가 없는 위치에는 좌표를 만들지 않는다. 회사 본사 주소를 근무지로 간주하지 않고 probable duplicate를 자동 병합하지 않는다.

## Fixture 정책과 개인정보

fixture는 2026-08-05에 공개 페이지에서 관찰한 필드의 작은 수동 축약본이다. 전체 설명, 연락처, 담당자, 이메일, 쿠키, 세션, 토큰, 광고·분석 식별자는 제외했다. 소스 구조는 예고 없이 변할 수 있으며 원본 소스 페이지가 항상 권위 있는 기준이다.

fixture를 추가할 때는 공개 표본 최소 요청 원칙을 지키고, `FixtureMetadata`에 시각·페이지 유형·증거 유형·sanitized 상태를 기록한다. 실제 대량 데이터나 비공개 원본 응답은 커밋하지 않는다.

## 설치와 검증


## 현재 한계

- 표본 수가 작아 모든 급여·위치·마감 변형을 대표하지 않는다.
- 잡코리아 목록 일반 검색에서는 급여가 항상 안정적으로 노출되지 않았다.
- 알바몬 내부 BFF는 문서화되지 않은 불안정 구조로 보고 fixture와 production 의존성에서 제외했다.
- 연봉, 주급, 건별, 다중 근무지, 근무지 미정, 상시모집은 이번 source fixture에서 계약 검증하지 못했다. 공통 순수 급여 parser의 연봉·주급·건별 표현만 단위 테스트한다.
- 좌표의 실제 근무지 일치 여부는 원문 경고와 함께 사용자에게 표시해야 한다.

## 다음 개발 단계

소스 이용 조건과 허용 수집 방식을 먼저 확인한 뒤, 현재 제한 안에서 연봉·다중 근무지·근무지 미정 표본을 소스별 한 건씩 추가해 parser 계약을 보강한다. 그 검증이 끝날 때까지 네트워크 fetcher나 UI를 연결하지 않는다.
